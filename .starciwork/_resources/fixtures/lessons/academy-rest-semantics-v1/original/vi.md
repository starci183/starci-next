# title

REST semantics: HTTP verb và status code contract
<!-- @starci/seperator -->
# description
<!-- @starci/seperator -->
Hiểu bản chất REST resource: vì sao mỗi HTTP verb ánh xạ tới một thao tác cụ thể (POST tạo, GET đọc, PUT thay toàn bộ, PATCH sửa một phần, DELETE xoá), status code (201/200/204/404) nói gì với client, và vì sao PUT idempotent còn POST thì không. Toàn bộ contract đều quan sát được qua status code và body trả về. Bài minh hoạ song song bằng TypeScript, Java, C# và Go — bạn chọn ngôn ngữ của mình.
