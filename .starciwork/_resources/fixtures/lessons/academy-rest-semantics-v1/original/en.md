# title
<!-- @starci/seperator -->
REST semantics: the HTTP verb and status code contract
<!-- @starci/seperator -->
# description
<!-- @starci/seperator -->
Understand REST resource semantics: why each HTTP verb maps to a specific operation (POST creates, GET reads, PUT replaces the whole resource, PATCH updates part of it, DELETE removes it), what the status codes (201/200/204/404) tell the client, and why PUT is idempotent while POST is not. The entire contract is observable through the returned status code and body. The lesson illustrates everything in parallel with TypeScript, Java, C#, and Go — pick your language.
