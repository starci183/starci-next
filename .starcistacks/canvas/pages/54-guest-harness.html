Thay đổi so với bản đã duyệt:

- Mới: Harness đọc được không cần phiên (service đã ghi "free for everyone", chỉ còn cổng phiên ở resolver).

- Bỏ ribbon tiến độ và "Việc tiếp theo" vì khách chưa có; nhãn mỗi phần là số lượng (5 build, 8 hướng dẫn, 12 tài liệu).

- Một nút chính "Bắt đầu build đầu tiên"; lời mời lưu là một dòng chữ nhỏ cuối trang. Chọn công cụ Claude Code hoặc Codex nhớ trên máy.

Thao tác: harnessHub, harnessBuilds, harnessBuild, harnessDocs, harnessDoc, harnessGuides, harnessGuide mở cho khách (chỉ phần nội dung, không có tiến độ); harnessDoctor, harnessTrials và bindHarnessBuild vẫn cần phiên. Phần tử Grammar: PageHeader, Tabs, Section kind="list", ChoiceChips.

Chặn agent đọc file .env

CLAUDE.md chỉ là lời dặn, agent vẫn có thể mở .env khi nó "tìm cách cho chạy được". Muốn chặn thật thì khai báo quyền deny và một hook chạy trước mỗi lần đọc file.

1. Khai báo quyền deny

Mở file cấu hình của dự án rồi thêm đoạn sau.

.claude/settings.jsonChép
{ "permissions": { "deny": ["Read(./.env)", "Read(./.env.*)", "Bash(cat .env*)"] } }
Bài trước
CLAUDE.md đầu tiên
Bài tiếp
Hook chặn --no-verify

Kiểm tra bài này

Kết quả doctor của máy bạn được lưu theo tài khoản.

Đăng nhập để xem mục nào đã đạt.
Chạy trên máy
npx @starci/next harness doctor --tool claude-codeChép
