Chặn agent đọc file .env

CLAUDE.md chỉ là lời dặn, agent vẫn có thể mở .env khi nó "tìm cách cho chạy được". Muốn chặn thật thì khai báo quyền deny và một hook chạy trước mỗi lần đọc file.

1. Khai báo quyền deny

Mở file cấu hình của dự án rồi thêm đoạn sau.

.claude/settings.jsonChép
{ "permissions": { "deny": ["Read(./.env)", "Read(./.env.*)", "Bash(cat .env*)"] } }

2. Thêm hook cứng

Quyền deny không bắt được mọi lệnh shell. Hook dưới đây từ chối mọi lệnh có nhắc tới .env.

.claude/hooks/no-env.mjsChép
const input = JSON.parse(await readStdin()) if (/\.env\b/.test(JSON.stringify(input.tool_input))) { console.error("Bị chặn: không đọc file .env") process.exit(2) }
Làm xong thì chạy harness trial để agent thật sự bị thử đọc .env.
