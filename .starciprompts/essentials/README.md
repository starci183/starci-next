# Essentials: the five parts

An Essentials lesson page has five parts, as tabs in this order (owner-approved 2026-11-21). Each part has one job; content of one part
never moves into another. Where a rule names a file, the file is in the content repository (`starci-next-seed-standard`,
`raw/essentials/<topic>/<lesson>/`), never in this app ([content concept](../../.starciwork/concepts/content.md)).

| Part          | Its one job                                                                                                                                                                                   | Lesson file                                                   | Rules                                  |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- | -------------------------------------- |
| 1. Mở đầu     | one interview night: five questions, each one essence of the concept                                                                                                                          | `sections/1-essential/quiz.yaml` (`essentials-quiz@1`)        | [1-mo-dau/](1-mo-dau/prompt.md)        |
| 2. Bản chất   | hands-on first: each moment of the night run as its lab scenario (guard off, wrong number; code; mechanism; guard on, right number), the learner's relayed run beside each flow, theory after | `sections/2-essence/vi.md`, `en.md`                           | [2-ban-chat/](2-ban-chat/rules.md)     |
| 3. Tìm sạn    | fix a buggy copy of the source, one bug per essence, until the tests pass                                                                                                                     | `bugs/source/`, `bugs/tests.yaml` (`essentials-bugs@1`)       | [3-tim-san/](3-tim-san/rules.md)       |
| 4. Challenges | the ladder of interviewer push-back questions                                                                                                                                                 | `sections/4-apply/challenges.yaml`                            | [4-challenges/](4-challenges/rules.md) |
| 5.
